# Local development

Use [the reproducible local development guide](../docs/LOCAL-DEVELOPMENT.md).
Only disposable PostgreSQL/Redis and synthetic fixtures are authorized for tests.
The historical fixed account credentials and raw SQL migration loop have been
removed. Do not copy a production environment file into local development.

The Node version, package locks, migration runner and CI checks are authoritative.
PDFs and supplier attachments are intentionally unavailable in this candidate.
